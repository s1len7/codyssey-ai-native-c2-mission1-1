# codyssey-ai-native-c2-mission1-1

내가 본 영화를 S~D 다섯 등급으로 나눠 정리하는 개인용 웹페이지 기획·초안 모음임. AI와 질문·답변을 주고받으며 기획서를 만들고, 두 AI가 만든 HTML 초안을 비교한 미션 1-1 결과물임.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `아이디어.md` | 5단계 아이디어 정리와 선정 이유 (16개 → TMDB API 1개 비채택, 총 15개) |
| `기획서.md` | 다섯 항목(누가 쓰나 / 무엇을 하려고 / 화면과 동작 / 필요한 자료 / 완성 기준) 기획서 |
| `영화_A_초안.html` | ChatGPT가 만든 초안. 외부 의존성 없음, 30편 |
| `영화_B_초안.html` | Gemini가 만든 초안. Tailwind CDN 사용, 15편 |
| `영화_A_수정본.html` | A초안에서 "미분류로 되돌리기"를 고친 수정본. 초안과 다른 이름으로 저장함 |
| `테스트_로그.md` | 다섯 가지 확인 항목 × 세 파일의 시각·단계별 기록 |
| `미션1_기록.md` | AI가 물어서 정한 것, 두 초안 비교, 선택·수정·재확인 기록 |
| `backup/` | 미션 안내 문서와 샘플 |

## 초안 실행

`영화_A_초안.html` 또는 `영화_B_초안.html`을 더블클릭하면 브라우저에서 열림. A는 인터넷 없이도 동작하고 B는 인터넷 연결이 필요함. 수정본 `영화_A_수정본.html`도 같은 방식으로 열어 확인할 수 있음.

## 기획서 요약

- **누가 쓰나**: 나 혼자 쓰는 개인용 페이지. 로그인 없음. GitHub에 코드만 공개
- **무엇을 하려고**: 본 영화를 5단계로 정리하고 장르별·티어별로 비교
- **화면과 동작**: 메인 한 화면에 티어리스트 + 영화 추가 패널. 카드는 포스터·제목·개봉 연도. 티어는 S / A / B / C / D 5단계 고정. 영화는 직접 입력. 수정은 티어만
- **필요한 자료**: 영화 목록(유명 영화 11편), 포스터 출처, 장르 목록, 백업 파일(JSON). TMDB API 연동은 API 키 노출 문제로 비채택
- **완성 기준**: `기획서.md` 5장 참고 — 기능, UI/UX, 데이터, 저장, 회귀 테스트, 최종 승인

## 미션 1-1 기록

두 AI가 같은 `기획서.md`로 만든 초안에는 일부 확장 기능(드래그, 영화 추가, 검색·필터, 백업 파일)이 빠져 있음. 선택은 `영화_A_초안.html`로 했고, A초안에서 등급을 매긴 영화를 "미분류"로 되돌릴 수 없던 문제를 고쳐 `영화_A_수정본.html`로 저장함. 수정본은 크롬에서 다시 실행해 수정 항목과 기존 기능을 재확인했고, 다섯 가지 확인 항목이 모두 됨. 자세한 내용은 `미션1_기록.md`와 `테스트_로그.md` 참고.
