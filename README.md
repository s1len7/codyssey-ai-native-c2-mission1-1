# 영화 티어리스트 (미션 1-1)

본 영화를 S / A / B / C / D / F 여섯 등급으로 나누어 정리하는 개인용 웹페이지 기획·초안 모음입니다. AI와 질문·답변을 주고받으며 기획서를 만들고, 두 AI가 만든 HTML 초안을 비교하는 미션 1-1의 결과물입니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `아이디어.md` | 5단계 아이디어 정리와 선정 이유 (16개 → TMDB API 1개 비채택, 총 15개) |
| `기획서.md` | 다섯 항목(누가 쓰나 / 무엇을 하려고 / 화면과 동작 / 필요한 자료 / 완성 기준) 기획서 |
| `영화_A_초안.html` | ChatGPT가 만든 초안. 외부 의존성 없음, 30편 |
| `영화_B_초안.html` | Gemini가 만든 초안. Tailwind CDN 사용, 15편 |
| `미션1_기록.md` | AI가 물어서 정한 것, 두 초안 비교, 선택·수정 기록 |
| `backup/` | 미션 안내 문서와 샘플 |

## 초안 실행

`영화_A_초안.html` 또는 `영화_B_초안.html`을 더블클릭하면 브라우저에서 열립니다. A는 인터넷 없이도 동작하고, B는 인터넷 연결이 필요합니다.

## 기획서 요약

- **누가 쓰나**: 나 혼자 쓰는 개인용 페이지. 로그인 없음. GitHub에 코드만 공개
- **무엇을 하려고**: 본 영화를 6단계로 정리하고, 장르별·티어별로 비교
- **화면과 동작**: 메인 한 화면에 티어리스트 + 영화 추가 패널. 카드는 포스터·제목·개봉 연도. 등급은 드래그앤드롭. 영화는 직접 입력. 수정은 티어만
- **필요한 자료**: 영화 목록(유명 영화 11편), 포스터 출처, 장르 목록, 백업 파일(JSON). TMDB API 연동은 API 키 노출 문제로 비채택
- **완성 기준**: 아직 정하지 않음

## 미션 1-1 기록

두 AI가 같은 `기획서.md`로 만든 초안은 핵심 기능(드래그, 영화 추가, 검색·필터, 백업 파일)이 빠져 있습니다. 선택은 `영화_A_초안.html`로 했고, 수정은 하지 않았습니다. 자세한 내용은 `미션1_기록.md`를 참고하세요.
